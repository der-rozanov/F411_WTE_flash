# Журнал изменений

Новые записи сверху.

## 23.10.2026 — настройки во flash (период мигания), запуск BMI270 после включения

- Новый модуль `svc_settings.c`: настройки в секторе 7 flash (0x08060000). Команды `blink [мс]`, `save`, `reboot`. Описание — [Стенд.md](Стенд.md), раздел «Настройки во flash».
- `STM32F411CEUX_FLASH.ld`: FLASH 512K → 384K, чтобы код не занял сектор настроек.
- Проверено на плате: значение переживает `reboot`, перепрошивку через `flash_dfu.bat` (стираются сектора 0–4) и отключение USB. Запись 300 поверх 150 подтверждает стирание. `save` при `arm` отклоняется. Стирание стоит ~1,06 с (измерено с ПК); `HAL_GetTick()` эту секунду не видит, поэтому время в ответе `save` убрано.
- Найдено при проверке питания: после холодного включения BMI270 не запускался (после сброса — всегда запускался). Добавлены повторные попытки, после выдёргивания USB — `boot init attempts 2`, гироскоп работает. Точная причина не выяснена.
- Сборка 0 ошибок, 0 предупреждений. На плате сейчас сохранён период 1000 мс.

## 23.10.2026 — исправлена консоль: команды, набранные руками, не распознавались

- Причина: `console_read_line()` собирал строку в буфер вызывающего, а он локальный в `bench_poll()` и затирался между проходами цикла. Скрипт слал команду одним пакетом, поэтому при первой проверке ошибка не проявилась.
- Исправление: строка копится в собственном буфере `svc_console.c`, вызывающему копируется готовая.
- Проверено на плате: команды по одному символу с паузами 80 мс (как с клавиатуры) и Backspace работают.
