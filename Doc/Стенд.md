# Испытательный стенд: консоль и модули

23.10.2026

Прошивка стенда опрашивает все узлы платы и управляет выходами по текстовым командам через USB COM-порт. Порт любой, скорость в терминале не важна (кроме 1200: она переводит плату в DFU). Ввод с эхом, Backspace работает, команда — по Enter.

## Команды

| Команда | Что делает | Пример ответа |
| --- | --- | --- |
| `help` | список команд | |
| `status` | всё сразу: время работы, датчики, моторы, питание | `imu: BMI270 running` |
| `imu` | CHIP_ID, гироскоп (°/с), акселерометр (g), температура чипа | `accel g: X=-0.026 Y=0.008 Z=-0.987` |
| `baro` | адрес, давление (Па), температура (°C) | `baro: SPL06 at 0x76, pressure 101238 Pa, temp 34.93 C` |
| `osd` | есть ли AT7456E | `osd: OSDM = 0x1B (AT7456E = 0x1B) -> found` |
| `power` | батарея (В), ток (А), RSSI и датчик скорости (мВ) | `battery 0.022 V, current 0.240 A, rssi 328 mV, airspeed 498 mV` |
| `i2c` | скан шины I2C1 | `i2c1: 0x76` |
| `servo <1-6> <мкс>` | импульс на выходе; `0` — выключить (линия в Low). Допустимо 500–2500 | `S4 = 1500 us` |
| `outputs` | заданный и измеренный на пине импульс S1–S6 | `S4: set 1500 us, pin 1500 us` |
| `arm` / `disarm` | разрешить / запретить моторы S1/S2 | `ARMED: S1/S2 = 1000 us. Props off!` |
| `pinio <1\|2> <0\|1>` | уровень на PC15 (Vbat на VTX/камеру) или PB10 (камера 1/2) | `pinio 1: pin reads 1` |
| `dfu` | перезагрузка в DFU-загрузчик | `Rebooting to DFU...` |

Ответы на английском намеренно: так терминал не зависит от кодировки.

## Безопасность моторов

- После старта все выходы S1–S6 с импульсом 0: линия в Low, регуляторы и сервы молчат.
- S1/S2 принимают `servo` только после `arm` и только 1000–1200 мкс (`MOTOR_TEST_MAX_US`).
- `arm` ставит на S1/S2 1000 мкс («газ ноль»), `disarm` — снова 0.
- Нет команд 10 с — автоматический `disarm` (`MOTOR_DISARM_TIMEOUT_MS`).

## Модули

Слои и правила — в [Руководство для агентов.md](Руководство%20для%20агентов.md), раздел 4.

| Файл | Что делает |
| --- | --- |
| `board.h` | константы платы: опора АЦП, делитель батареи 11, датчик тока 25 мВ/А, период выходов |
| `svc_console.c` | кольцевые буферы приёма (из прерывания USB) и вывода (в USB кусками по 256 байт), сборка строки с эхом |
| `drv_bmi270.c` | BMI270 по SPI2: холостое чтение для перехода в SPI, загрузка конфигурации Bosch, ±2000 °/с 200 Гц, ±16 g 100 Гц |
| `bmi270_config.c` | конфигурационный файл BMI270 (8192 байта) из [Bosch BMI270_SensorAPI](https://github.com/boschsensortec/BMI270_SensorAPI), лицензия BSD-3, без изменений |
| `drv_spl06.c` | SPL06-001 по I2C1: сам находит адрес 0x76/0x77, читает калибровку, непрерывное измерение 32 раза/с, пересчёт по формулам даташита |
| `drv_at7456.c` | AT7456E по SPI2: только проверка присутствия (регистр OSDM = 0x1B после сброса, как в Betaflight) |
| `drv_power.c` | ADC1 + DMA по кругу, пересчёт в мВ и мА |
| `drv_outputs.c` | ШИМ S1–S6 и измерение импульса на самом пине: чтение уровня GPIO + счётчик таймера |
| `bench_commands.c` | команды консоли, защита моторов, мигалка светодиодов |

Изменения в сгенерированных файлах, только в секциях `USER CODE`:

- `main.c`: `bench_init()` после инициализации периферии, `bench_poll()` в цикле перед `Bootloader_Poll()`.
- `usbd_cdc_if.c`: приём в прерывании только кладёт байты в консоль; команда `dfu` переехала в стенд. Касание на 1200 бод осталось в обработчике USB, поэтому прошивка без кнопки работает, даже если стенд сломается.

Драйвер ICM42688P был написан и удалён: на нашей плате BMI270. Если понадобится плата новее марта 2023, драйвер придётся написать заново.

## Проверка на плате (23.10.2026, питание только от USB)

| Узел | Результат | Как проверено |
| --- | --- | --- |
| USB, прошивка без кнопки | работает | касание 1200 бод и команда `dfu`, прошивка ~7 с |
| Светодиоды | оба мигают по очереди | глазами (владелец) |
| BMI270 | работает | CHIP_ID 0x24, модуль ускорения 0,99–1,03 g, шум гироскопа ~0,2 °/с, 3 положения платы |
| SPL06-001 | работает | ID 0x10, 0x76, 101 238 Па, 34,9 °C |
| AT7456E | отвечает | OSDM = 0x1B; работа OSD с камерой не проверялась |
| АЦП | читается | батарея 0,02 В (нет батареи), ток 0,24–0,32 А, RSSI ~325 мВ, скорость ~495 мВ — входы висят в воздухе |
| S1–S6 | работают | измерение на пине: 999–2500 мкс, ошибка ≤ 2 мкс |
| Защита моторов | работает | без `arm` и выше 1200 мкс — отказ; автодизарм через 10 с |
| PINIO PC15, PB10 | пины переключаются | чтение уровня пина; что включается на плате — не проверено |
| UART1, UART2 | не проверено | нужна перемычка TX–RX или устройство |
| Пищалка | не проверено | пищалки нет, BZ- — только пятак |

Температура 34 °C у барометра и гироскопа — это нагрев платы от МК и стабилизатора, не ошибка.

## Известные ограничения

- `imu`, `baro` — одно чтение по команде, без фильтров и калибровки нуля.
- `outputs` блокирует цикл до 40 мс на выход (до 240 мс на все). Для стенда допустимо.
- Ток без батареи не ноль: проверить с батареей, нужна ли поправка нуля.
- Если терминал не открыт, вывод копится в буфере 2 КБ, лишнее отбрасывается.
